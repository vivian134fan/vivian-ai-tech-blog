## 導讀

《AI 科技資訊前沿》二〇二六年十一月六日（星期五）報道：月之暗面於 Hugging Face 開放 Kimi K3.1 Pro 完整權重，總參數 2.8 萬億，倉庫共 96 個檔案、合共約 1.56 TB；第三方機構 QuestMobile 發布二〇二六年秋季榜，豆包月活躍用戶達 4.19 億；Meta 與 OpenAI 於同日各自收購一間編程工具初創企業；OpenAI 發布安全研究報告，指一條自動化流水線生成 948 個 Linux 提權漏洞利用程式；優必選旗下優世界 U1 系列機械人於烏鎮峰會再度展出，全渠道訂單 13,361 台、公司預計年內交付 1,500 至 2,000 台；美股十一月五日收市，納斯達克綜合指數單日下跌 5.52%。以上資訊僅供參考，不構成任何投資建議。

## 新聞內容

### 一・產品發佈・月之暗面開源 Kimi K3.1 Pro 完整權重・總參數 2.8 萬億

月之暗面（Moonshot AI）於十一月四日在 Hugging Face 開放 Kimi K3.1 Pro 完整模型權重，倉庫 moonshotai/Kimi-K3.1-Pro 共 96 個檔案，合共約 1.56 TB，採用 MXFP4 權重、MXFP8 激活格式，平台頁面顯示無等候名單、無申請門檻。該模型採用混合專家架構，總參數 2.8 萬億，每次推理激活約 1,040 億，設 896 個專家，每個 token 選用 16 個專家加 2 個共享專家，共 93 層；上下文長度 1,048,576 個 token，並內置約 4.01 億參數的視覺編碼器 MoonViT-V2，原生支援圖文混合輸入。

架構方面，K3 系列原有的 24 層 Gated MLA，在 K3.1 Pro 改為 Gated DeepSeek Sparse Attention：生成時由 32 個輕量索引頭為歷史 token 打分，選出最相關的 2,048 個再計算注意力，其餘 69 層仍為 KDA 結構。評測方面，Agent Arena 平台基於全球用戶超過 1.75 萬次真實長任務會話，將 K3.1 Pro 列為開放權重模型第一、全榜第十三，官方稱工作、編程、聊天三類任務均為開放模型第一，淨改進率 5.1%，高於上一代的 0.9%。

授權與部署方面，模型採用 MIT 改良版授權：年收入超過 2,000 萬美元的模型服務商須另行簽約，月活躍用戶超過 1 億或月收入超過 2,000 萬美元的產品須在介面標明型號。官方建議以 vLLM、SGLang、TokenSpeed 部署，完整權重運行約需 8 張 B300 顯示卡；API 定價為每百萬 token 輸入 2 美元、緩存輸入 0.2 美元、輸出 10 美元。上述評測名次屬平台及官方口徑，實際表現視乎具體任務與部署條件。

### 二・中國市場・QuestMobile 秋季榜：豆包月活 4.19 億・DeepSeek 錄得負增長

十一月三日，第三方數據機構 QuestMobile 發布「二〇二六年秋季中國移動互聯網實力價值榜」。億級應用用戶規模增長榜前五名依次為：千問月活躍用戶 1.58 億、按年增長 5,077%；抖音商城 1.69 億、增長 240%；豆包 4.19 億、增長 144%，為億級榜單中絕對體量最大；紅果免費短劇 4.29 億、增長 82%；汽水音樂 1.71 億、增長 43%。

AI 原生應用用戶規模前五名為豆包、千問、DeepSeek、元寶及螞蟻阿福。其中豆包 4.19 億，較第二名多出超過一倍；DeepSeek 月活躍用戶 1.23 億、按年下跌 15.2%，屬榜單中少見的負增長；元寶為 3,733 萬。背景方面，千問於二〇二五年底以獨立消費端應用重新推出，一年內由較低基數升至 1.58 億；豆包依託短片生態分發，於本年成為內地體量最大的 AI 原生應用。

值得注意的是，榜單僅統計月活躍用戶，不含付費率、使用時長及留存數據；千問同期依靠補貼及直播帶貨推高用戶規模，付費轉化情況官方未有披露；DeepSeek 的下滑與其重心轉向企業服務及開源生態有關，屬第三方推算，公司方面未作評論。月活躍用戶規模不等於商業化能力，榜單數據僅反映用戶側變化。

### 三・併購融資・Meta 與 OpenAI 同日各收購一間編程工具初創企業

美東時間十一月四日至五日，兩間美國人工智能公司於同日各自宣布收購一間編程工具初創企業。Meta 收購多智能代理編程工作台 Conductor：該產品於二〇二五年七月上線，其創辦人及技術總監將加入 Meta 超級智能實驗室，向 Nat Friedman 及 Alexandr Wang 匯報；官方同時宣布，Conductor Cloud 將於十一月十三日轉為唯讀，十一月二十日關閉，逾 10 萬名用戶受影響，需在此之前匯出資料。

OpenAI 則收購 Pierre Computer Company。該公司於二〇二三年成立，累計融資約 2,400 萬美元，交易金額未有披露。其核心產品 Code Storage 是面向 AI 智能代理工作負載的 Git 託管基建，已服務 Lovable、Bolt、Amp 等客戶；Trees 與 Diffs 分別負責檔案瀏覽及代碼改動審查，現已整合進 Codex；Pierre 的開源項目將維持開放。據業界報道，OpenAI 同周另公布自研 Git 後端 Pando，生產環境代碼推送中位延遲降低近八成，業界解讀今次收購屬補齊代碼存儲與審查一環，並與微軟旗下 GitHub 在 AI 原生開發基建上正面競爭。

人事方面，Anthropic 旗下 Claude Code 與桌面端 Cowork 產品負責人 Cat Wu 於同日離職，加入 OpenAI，負責核心產品團隊的產品管理。兩宗交易均未披露金額，無法評估溢價水平；Conductor 用戶須於十一月十三日前完成資料匯出，屬已確認的服務中斷風險。

### 四・安全監管・OpenAI 報告：自動化流水線生成 948 個 Linux 提權漏洞

美東時間十一月四日，OpenAI 發布安全研究報告，公布一條覆蓋漏洞發現、動態驗證、可利用性評估、補丁生成及人工覆核的自動化流水線。報告稱，在二〇二六年十月中旬的一次運行中，流水線識別 2,308 個 Linux 內核候選樣本，動態復現 1,724 個漏洞，生成 291 個資訊洩漏概念驗證程式，以及 948 個可令普通本地用戶取得最高權限的提權利用程式。全流程 API 成本為 121.3 萬美元，平均每個提權利用程式 1,279 美元；按 Pwn2Own（單項 2 萬美元）及 TyphoonPWN（單項 7 萬美元）歷史賞金水平估算，該批利用程式的假設價值為 1,890 萬至 6,630 萬美元，約為成本的 16 至 55 倍。

進展方面，OpenAI 稱代理至少使用 10 種全新的漏洞利用技術，相關技術已經第三方內核專家核驗；按 Linux 內核社區建議，研究團隊先行提交嚴重漏洞，並與 Patch the Planet 合作推進其餘報告及補丁。在掃描期間的十日內，社區已修補或排期處理超過 100 個提權漏洞，另有約 300 個仍在公開討論。

限制方面亦須如實說明：測試於受控研究環境、以常規桌面發行版進行，屬模擬賽事威脅模型；報告未經第三方獨立覆核，補丁仍須人手審核；OpenAI 未公布所用模型名稱，僅稱為「即將推出的網絡安全模型」。上述估算屬報告方口徑，僅供參考。

### 五・機械人硬件・優必選優世界 U1：訂單 13,361 台・年內交付 1,500 至 2,000 台

十一月二日至五日，世界互聯網大會烏鎮峰會「互聯網之光」博覽會舉行，優必選（09880.HK）旗下消費級品牌優世界 U1 系列再度展出。產品為全尺寸超仿生人形機械人，男款身高 183 厘米、體重 42 公斤，女款身高 168 厘米、體重 35.2 公斤；全系 88 個自由度，配雙支點仿生頸椎及 30 多種微表情，官方稱可識別 20 多種細粒度情緒、準確率超過九成，並支援本地加密存儲交互記憶。售價分三個檔次：半身版 11.98 萬元、全尺寸版 16.98 萬元、頂配版男款 99 萬元、女款 88 萬元。產品不能自主行走，單次充電續航 2 至 4 小時，僅限成年人購買，官方明確表示不主打家務場景。

訂單與交付方面存在明顯落差：優必選於六月二日開啟預售，定金 3,000 元、可以退還；六月三十日發布會公布全渠道訂單 13,361 台，對照二〇二五年全年全尺寸人形機械人銷量 1,079 台；至八月底業績會，財務總監張鉅將年內實際可交付量調整為 1,500 至 2,000 台。首批交付的三家客戶為上海永達、北京波士及韓國 Galaxy 機械人樂園，全部屬商用場所，用途為導覽、接待及引流。產能瓶頸方面，據報道涉及仿生硅膠皮膚良品率、眉毛睫毛手工植入、非標微型伺服舵機等因素，加上柳州工廠受水災影響，投產推遲兩至三個月。

行業層面，高工諮詢於十一月三日行業年會預計，全年中國人形機械人整機出貨超過 5 萬台、市場規模超過 100 億元，但增速低於年初預期，第四季起融資轉趨審慎；中國人形機械人與具身智能百人會數據顯示，上半年中國出貨超過 4 萬台、佔全球約 97%。上述預測屬行業機構口徑。

### 六・資本市場・美股十一月五日大跌・納指單日跌 5.52%

美東時間十一月五日收市，美國三大指數全線下跌：道瓊斯工業平均指數跌 1,833.06 點、跌幅 3.44%，收報 51,523.06 點；標準普爾 500 指數跌 334.89 點、跌幅 4.36%，收報 7,353.73 點；納斯達克綜合指數跌 1,421.52 點、跌幅 5.52%，收報 24,315.00 點，為二〇二五年四月以來最大單日跌幅（新華社、美聯社、Kiplinger 多鏈一致）。

板塊與個股方面，標準普爾 500 指數十一大板塊全線下跌，科技板塊跌 7.30%、工業板塊跌 4.12%；個股方面，英偉達跌 9.3%、超威半導體跌 17.3%、美光跌 17.5%、SanDisk 跌 22.3%、CoreWeave 跌 9.8%、高通跌 9.5%。恐慌指標方面，芝加哥期權交易所波動指數（VIX）早段突破 25，單日升幅超過 45%；納指較十月六日高位 27,599.79 點低 11.9%，技術上進入調整區間；南韓 KOSPI 指數同日跌 5.3%。其他市場方面，布蘭特原油上升 3.9% 至每桶 98.29 美元；10 年期美國國債息率由 4.90% 降至 4.84%。

市場解釋方面，新華社引述海納國際集團衍生工具策略師 Chris Murphy 稱，資金由晶片股向外輪動，反映市場對人工智能支出節奏及融資成本的憂慮增加；美聯社報道指，市場同時關注數據中心建設可能放緩、借貸成本上升，以及部分地區對新建數據中心審批轉趨審慎。本則為市場行情與各方解釋的如實轉述，不作任何推薦或預測，不構成任何投資建議。
